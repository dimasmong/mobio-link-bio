## 1. Environment Variables & Secrets Reference

MOBIO enforces a strict separation between public configuration, encrypted production secrets, and local development simulation.

| Variable Name | Type | Scope | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `CF_ACCESS_TEAM_NAME` | Secret | Production | **Yes** | Your Cloudflare Zero Trust team domain (e.g. `my-team` from `my-team.cloudflareaccess.com`). Used to fetch public JWKS keys for cryptographic RS256 signature verification. |
| `CF_ACCESS_AUD` | Secret | Production | **Yes** | The 64-character Application Audience (AUD) tag generated by Cloudflare Access for your `/studio` application. Used to verify the JWT `aud` claim. |
| `ADMIN_EMAIL` | Secret | Production | Optional | An email whitelist. If set, only this email address will be permitted access to MOBIO Studio, even if other users pass the Cloudflare Access login screen. |
| `LOCAL_DEV_ADMIN_EMAIL`| Plaintext | Local (`.dev.vars`) | Optional | Simulates an authenticated administrator when running `npm run dev` on `localhost`. Strictly rejected in production builds. |
| `VALUE_FROM_CLOUDFLARE`| Variable | All (`vars`) | Optional | Informational variable injected into Worker context. |

### How to Set Production Secrets
Never put production credentials into `.dev.vars` or commit them into Git. Set them directly via the Wrangler CLI targeting your instance configuration:
```bash
# For independent self-hosted instances:
npx wrangler secret put CF_ACCESS_TEAM_NAME --config wrangler.instance.json
npx wrangler secret put CF_ACCESS_AUD --config wrangler.instance.json
npx wrangler secret put ADMIN_EMAIL --config wrangler.instance.json
```
Or manage them in the Cloudflare Dashboard under **Workers & Pages** ➔ **Your Worker** ➔ **Settings** ➔ **Variables and Secrets**.

## 2. Wrangler Configuration Model

MOBIO uses an explicit dual-configuration architecture to protect the production deployment while granting self-hosters complete independence:

| File | Purpose | Tracked in Git? | Scope |
| :--- | :--- | :--- | :--- |
| `wrangler.json` | Project maintainer's production configuration (`me.dimasmong.web.id`). **Do NOT edit.** | ✅ Yes | Upstream production |
| `wrangler.example.json` | Clean reference template with clear placeholders. | ✅ Yes | Reusable reference |
| `wrangler.instance.json` | **Your local instance configuration.** Contains your personal D1 UUID and R2 bucket. | ❌ No (`.gitignore`) | Your independent deployment |

### Instance Configuration Reference (`wrangler.instance.json`)

To create your instance configuration:
```cmd
:: Windows Command Prompt:
copy wrangler.example.json wrangler.instance.json

:: PowerShell / macOS / Linux:
cp wrangler.example.json wrangler.instance.json
```

```json
{
  "$schema": "./node_modules/wrangler/config-schema.json",
  "name": "my-mobio-link-bio",
  "main": "./workers/app.ts",
  "compatibility_date": "2025-10-08",
  "compatibility_flags": ["nodejs_compat"],
  "workers_dev": true,
  "preview_urls": false,
  "observability": {
    "enabled": true
  },
  "upload_source_maps": true,
  "vars": {
    "VALUE_FROM_CLOUDFLARE": "Hello from Cloudflare"
```

## 3. Cloudflare Bindings

### Cloudflare D1 Database (`DB`)
- **Binding Name:** `DB`
- **Purpose:** Stores profile identity, vertical links, contact methods, explore items, appearance settings, and privacy-safe interaction telemetry.
- **Draft/Publish Architecture:** Writes occur in isolated draft tables or draft rows, which are atomically promoted to published state upon user confirmation.

### Cloudflare R2 Bucket (`MEDIA_BUCKET`)
- **Binding Name:** `MEDIA_BUCKET`
- **Purpose:** Cloudflare's S3-compatible zero-egress object storage for user-uploaded profile avatars, custom icon graphics, banner covers, and photo galleries.
- **Access Endpoints:**
  - Authenticated Studio preview: `GET /api/studio/media/:id/preview`
  - Public serving: `GET /api/public/media/:id`

## 4. Custom Domain Setup

To bind MOBIO to your own custom domain (e.g., `bio.example.com` or `links.example.com`):

1. **Verify DNS:** Ensure your domain is active on Cloudflare DNS.
2. **Add Custom Domain in `wrangler.instance.json`:**
   ```json
   "workers_dev": false,
   "routes": [
     {
       "pattern": "bio.example.com",
       "custom_domain": true
     }
   ]
   ```
3. **Deploy:** Run `npx wrangler deploy --config wrangler.instance.json`. Cloudflare automatically provisions an SSL/TLS certificate and routes traffic to your Worker.
4. **Update Access Application:** Ensure your Cloudflare Access Application domain in Zero Trust points to `bio.example.com` with path `studio`.

## 5. Bilingual Engine Settings

MOBIO V4.2 features a full bilingual engine with English as the universal default:

- **Default Language:** English (`en`)
- **Supported Languages:** English (`en`), Indonesian (`id`)
- **Persistence:** Synchronized via `mobio_lang` HTTP cookie (`SameSite=Lax`, max-age 1 year) and client `localStorage`.
- **SSR Alignment:** Root loader in `app/root.tsx` parses the cookie and renders `<html lang="en|id">` on the server to prevent visual flash and hydration mismatch.
- **Dynamic Content Fallback:** In [`app/lib/i18n.ts`](../app/lib/i18n.ts), `getLocalizedText()` checks the active language first, falls back to the alternate language if missing, and provides a neutral fallback if both are empty.

## 6. Fallback Content Configuration

If D1 database connectivity is unavailable or if a fresh database contains empty profile strings, MOBIO automatically falls back to [`app/data/profile.ts`](../app/data/profile.ts):

- **Default Name:** `"Your Name"`
- **Default Handle:** `"@username"`
- **Default Avatar:** Automatic monogram initial ("YN")
- **Default Links:** Empty list (renders clean fallback prompt)
- **Default Explore:** Empty list (renders clean fallback prompt)
- **Default Contact:** Empty list (renders clean fallback prompt)

To customize offline defaults directly in code, edit `app/data/profile.ts`.

## 7. Theme Engine & Preset Reference

The MOBIO design system is driven by atomic CSS tokens computed dynamically at runtime:

- **30 Color Theme Presets:** Frost Aurora, Dark Sapphire, Emerald Glass, Violet Neon, Sunset Amber, Rose Quartz, Cyberpunk Slate, and 23 additional calibrated palettes.
- **20 Layout Presets:** Minimal Stack, Neo Capsule, Soft Grid, Split Composition, Compact Center, Magazine Editorial, and 14 other thumb-friendly responsive layouts.
- **10 Profile Card Styles:** Floating Glass, Immersive Card, Minimalist Monogram, Bordered Glow, Split Header, Pill Minimal, and 4 other variations.
- **3 Card Sizes:** Compact (`sm`), Standard (`md`), Spacious (`lg`).
- **24 Font Presets:** Organized into Modern Sans, Elegant Serif, Tech Mono, and Expressive Display families with automatic Google Fonts streaming.
- **Liquid Glass Materials:** Specular highlights (`inset 0 1.5px 1px 0 rgba(255, 255, 255, 0.95)`), backdrop filters (`blur(24px) saturate(180%)`), and multi-layer floating drop shadows.
